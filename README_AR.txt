Solo Rift - Native Android APK

هذه نسخة تطبيق Android أصلية للعبة سولو، مبنية بدون Game Engine.
الكود يستخدم Java + Android Canvas + SharedPreferences.

ما الذي تم تحويله من بوت واتساب؟
- .سولو فايت أصبح زر "افتح بوابة قتال".
- نظام الوحوش والندرات والقدرات أصبح قتال مرئي داخل شاشة Battle.
- المحارب، النقاط، الإحصائيات، المتجر، الحقيبة، المهام، التاريخ كلها أصبحت شاشات داخل التطبيق.
- الحفظ صار محلياً على الجهاز بدل ملفات قاعدة بيانات البوت.

طريقة البناء بدون Android Studio:
1) ارفع محتويات هذا المجلد إلى GitHub repository، وليس ملف ZIP نفسه.
2) افتح تبويب Actions.
3) شغل workflow اسمه: Build Solo Rift APK.
4) بعد انتهاء التشغيل، حمل Artifact باسم SoloRift-debug-apk.
5) فك الضغط وستجد app-debug.apk.

مهم:
- لا تثبت ملف Artifact zip مباشرة.
- فك الضغط وخذ app-debug.apk فقط.
- إذا ظهر تعذر تثبيت، احذف أي نسخة قديمة بنفس اسم التطبيق أولاً.
